# 디벗 양품화 업무 안내

콜센터 상담 참고용 정적 다중 페이지 사이트입니다. 순수 HTML·CSS·JavaScript를 사용하며 설치·패키지·빌드·백엔드가 필요하지 않습니다.

## 구현 범위

- Phase 1: 두 업무 영역, 학교 7단계, 사업 안내 4개 페이지, 공통 헤더·메뉴·푸터와 모바일 대응
- Phase 2: 제공 자료에 근거한 상세 업무 안내, 절별 출처, 자료 간 확인 필요 표시, 문의 경로
- Phase 3: 전체 페이지 검색·현재 페이지 인쇄, 모바일 접이식 목차와 이동·콘솔 점검
- Phase 4: 원본 자료 대조, 연도·제품명 구분 보완, 재검토·남은 일 기록
- 학교 업무 페이지: ‘학교가 할 일 → 확인 방법 → 주의·예외’ 순서
- 원본 자료·개인정보·계정 및 비밀번호 예시·공식 로고·직인은 게시하지 않음

## 실행 및 확인

1. `index.html`을 브라우저에서 엽니다. 설치나 빌드는 필요 없습니다.
2. 학교 7단계와 사업 안내 4개 페이지의 내용을 확인합니다.
3. 상세 페이지의 메뉴·이전/다음·전체 목록·문의 경로를 확인합니다.
4. 각 절의 출처 링크가 ‘자료·출처 및 확인 필요 사항’의 해당 자료로 이동하는지 확인합니다.
5. `pages/school/preparation.html`을 직접 열어 공통 디자인과 상대 경로를 확인합니다.
6. 모바일 너비에서 본문 위 목차를 펼쳐 이동하고, 긴 표를 가로로 스크롤합니다.
7. 공통 검색창에 검색어를 넣어 제출합니다. 예: `수리동의서`, `USB 차단`. 결과 링크에서 관련 페이지로 이동합니다.
8. [현재 페이지 인쇄]를 누릅니다. 인쇄에서는 헤더·검색 결과·메뉴를 제외한 현재 페이지 본문과 출처를 출력합니다.

상대 경로를 사용하므로 정적 서버의 루트 또는 하위 경로에서도 사용할 수 있습니다. 공통 메뉴는 JavaScript로 삽입합니다. JavaScript가 꺼져도 본문·출처·이전/다음 링크는 사용할 수 있습니다. 실제 문의 서비스나 개인정보 입력 폼은 이 사이트에서 제공하지 않습니다.

호스팅 시에는 개인정보 검토 전 `reference/`를 업로드 대상에서 제외하세요.

## Phase 2 자료 검토

PDF 2개(67쪽·16쪽), PPTX 1개(67슬라이드), DOCX 1개, TXT 1개를 텍스트로 읽고 이미지 4개를 시각 확인했습니다. PDF·PPTX의 이미지로만 된 화면·서식 세부 글자는 텍스트 추출로 검증하지 않았고, 읽지 못한 부분을 추측하지 않았습니다.

근거와 충돌 목록은 `pages/sources.html`에 정리했습니다. PDF와 PPTX를 같은 버전으로 간주하지 않았으며 상담스크립트는 ‘운영 기준 확정 전 검토본’으로 취급했습니다. 외부 서비스에 접속하거나 현재 운영 정책·일정을 조회하지 않았습니다.

## Phase 4 피드백 및 수정

원본 자료와 기존 구현을 대조해 2024년 OS별 제품명과 2022~2026년 보급 연도별 관리 사업자 구분이 빠져 있음을 확인하여 수거 품목 페이지와 출처 대응표에 추가했습니다. 검색 색인도 현재 HTML에서 다시 생성했습니다.

분석·1차 피드백·반영 내역·2차 검토·잔여 확인 항목은 `docs/phase-4-review.md`에 기록했습니다. 자료끼리 충돌하는 운영 기준은 계속 ‘확인 필요’로 표시합니다.

## Phase 3 점검 결과

변경 파일은 `assets/js/common.js`, `assets/css/common.css`, `README.md`입니다. 업무 본문과 HTML 파일은 변경하지 않았습니다.

- 첫 화면: 업무 영역 2개, 학교 단계 링크 7개 확인
- 정적 경로: HTML 14개의 내부 링크·자산·앵커 265건 검사, 오류 0건
- Chrome 실제 실행: 파일 직접 열기와 로컬 정적 서버의 `/manual/` 하위 경로에서 각 14개 페이지 확인(총 28회)
- 메뉴: 전체 페이지의 공통 메뉴, 상세 목차의 현재 페이지 표시, 모바일 목차 접기·펼치기 확인
- 검색: 28회 실행, 학교 준비 페이지 등 본문 검색 확인. 다중 공백·빈 검색어·검색 결과 없음·HTML 형태 입력의 안전한 처리 확인
- 모바일: 전체 페이지 390px에서 본문 가로 넘침 없음. 출처 페이지 320px 추가 확인. OS별 준비와 출처 화면의 캡처를 시각 확인
- 인쇄: 전체 페이지의 인쇄 버튼 호출 확인, 출처 페이지를 Chrome PDF로 실제 출력 성공
- 콘솔: 최종 순회에서 JavaScript 예외·console.error·브라우저 오류 로그 0건. 기본 favicon.ico 요청의 404는 빈 데이터 아이콘으로 방지
- 검사 과정의 브라우저·임시 정적 서버는 종료했으며 패키지나 빌드 도구는 추가하지 않음

검색은 공통 JS의 `searchPages`에 수록한 공개 HTML 본문 14개를 대상으로 합니다. 원본 `reference/` 파일은 검색하지 않습니다. 네트워크 요청 없이 파일 직접 열기를 지원하기 위한 정적 색인이므로, HTML 본문·제목·경로를 수정할 때 색인도 함께 갱신해야 합니다.
