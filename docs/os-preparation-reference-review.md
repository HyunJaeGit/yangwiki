### 두 번째 피드백과 마무리 수정

처음에는 등록된 다른 조직의 기기를 옮기는 절차만으로 수량 부족 원인을 설명할 수 있어 보였다. 그러나 2025 크롬 매뉴얼은 CEU 누락 기기 등록 절차를 목차에만 두고 실제 단계를 설명하지 않는다. 미검색 상황을 조직 이동 사례와 분리해 ‘검색됨/다른 조직’과 ‘검색되지 않음/권한 확인’ 분기를 추가했다. 실물 시리얼 대조와 이동 뒤 조직 정책 재확인도 넣었으며, 일괄 이동 가능 여부는 자료에서 정하지 않는다고 표시했다.


## 사용자 확인에 따른 정책 적용 시점 보완

2026-10-29 사용자 설명에 따라 게스트 모드와 AMA의 정책 차이를 ‘자료 간 충돌’로 취급하지 않는다. 자료는 평상시 학교 정책과 양품화 작업 상황을 각각 설명한다. 평소에는 차단하고, 양품화 소프트웨어 업데이트·포맷이 필요한 동안만 관련 기능(크롬북 파워워시·게스트 모드, AMA 공장초기화·USB 전송)을 한시 허용한 뒤 작업 완료 후 평상시 차단 상태로 복구한다. 이 운영 적용 시점은 사용자 확인 정보로 `additional_info.md`에도 기록했다. AMA 화면의 색상·항목명 차이는 남지만, 실행 기준은 작업 중 허용·완료 후 차단이라는 실제 기능 상태다.
