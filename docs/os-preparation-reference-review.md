# OS별 수거 준비 자료 대조

검토일: 2026-10-29. 사용자가 추가한 2025년·과거 자료 중 현재 양품화 수거 준비와 관련된 내용을 검토했다. 외부 웹의 최신 제품 정책으로 보충하지 않았다. 쪽수는 PDF 페이지 순서다.

## 확인 자료

- `reference/2025년_서울시교육청_디벗 기기 매뉴얼_크롬.pdf` (66쪽): Workspace 관리자 화면 16쪽, 기기 설정 30쪽, 게스트 차단 33쪽, CEU·재등록·현황·해제 50~52쪽, MDM 연계 56~57쪽.
- `reference/2025년_서울시교육청_디벗 기기 매뉴얼_안드로이드.pdf` (94쪽): AMA 단말현황·다운로드 69~70쪽, 초기화와 계정 구분 76~77쪽, 차단 정책 82쪽.
- `reference/2025년_서울시교육청_디벗 기기 매뉴얼_아이패드.pdf` (82쪽): 학적·SFTP·졸업 계정 관리 29·37쪽, MDM 초기화 63쪽, 평상시 권장 정책 64~65쪽.
- `reference/2025년_서울시교육청_디벗 기기 매뉴얼_윈도우.pdf` (78쪽): 업체 초기화 19쪽, 졸업·전출 계정 관리 40~41쪽.
- `reference/2025년_서울시교육청_디벗 기기 매뉴얼_웨일북.pdf` (52쪽): 관리 도구 18~19쪽, 졸업 계정 삭제 30쪽, 강제 재등록 38쪽, 기기 식별 44쪽.
- `reference/(과거자료)_교육부_학교 스마트단말 관리시스템 매뉴얼.pdf` (92쪽): 초기화 11~13쪽, 차단 설정 17쪽, CSV 다운로드 64쪽, 단말 상세 정책정보 67쪽. 발행연도는 확정하지 않았다.
- `reference/2025년_서울시교육청_디벗 스마트기기 AS 안내 리플릿.pdf` (2쪽): 수리비·접수·사업자별 연락 안내. OS별 사전 설정 자료가 아니므로 수거 준비 페이지에 추가하지 않았다.
- 대조 기준: `2027학년도 디벗 양품화 시행 가이드(학교연수자료).pdf` 14~34쪽, `2027학년도 디벗 양품화 안내자료(실무가이드).pdf` 4~5·13쪽. 기존 연수 PPTX v4.6의 14·19~20·28~30·37번 슬라이드 텍스트도 대조했다.

PDF 텍스트를 추출해 관련 절을 직접 읽었다. 이미지 속 UI·텍스트 없는 페이지까지 육안 검증한 것은 아니다. HWP는 이번 OS별 검토의 근거로 사용하지 않았다. 원본·추출문·학교 및 개인 식별정보·계정·비밀번호·로고·직인은 사이트에 추가하지 않았다.

## 정보 배치와 구현

- `pages/school/os-preparation.html`: 02단계 요약 유지, 상세 페이지 연결, AMA 충돌 표시·앵커 추가.
- `pages/school/os-management.html`: 보충 상세 신설. OS별 관리 도구 표 → 크롬북 Workspace·CEU → 다른 OS 관리자 작업 → 출처별 차이 순서.
- `pages/school/transfer.html`: 관리전환 영역 앵커·상호 링크, 관리자 정보 제출 시기 명확화.
- `assets/js/common.js`: 학교 보충 목차, 변경 페이지·새 페이지 검색, 패치노트 갱신.
- `additional_info.md`: 사용자 요청에 따른 자료 검토 메모를 운영 정보와 분리. 기존 AMA·비용 기록의 근거 상태 변화를 이력으로 보존.
- `패치내역.md`: 사이트 안내·구조 변경만 기록.

기본 7단계를 늘리지 않고 OS별 준비와 관리전환 사이에서 찾아볼 수 있는 보충 페이지로 구성했다. 일반 계정 관리 매뉴얼 전체를 복제하거나 수업 설정·신규 도메인·CEU 구매·A/S 연락처 등을 추가하지 않았다.


## 검증 결과

- 전체 HTML 22개: 로컬 링크·자산·앵커 247개, 중복 ID, 태그 중첩 검사 통과.
- Chrome headless 실제 DOM 14개 검사 통과: 공통 메뉴·학교 보충 목차, 새 페이지 현재 위치, AMA·관리전환 직접 링크 펼침, CEU 검색, 최신 패치노트, 인쇄 전 펼침·후 상태 복구, 390px 프레임의 문서 가로 넘침 없음.
- `git diff --check` 통과. 빌드·패키지·백엔드 추가 없음. 검토 도구·추출 텍스트·브라우저 프로필은 OS 임시 폴더에만 저장.
- 실제 MDM·Workspace·Whalespace 관리자 화면에 접속해 정책을 변경한 것은 아니다. AMA 색상 의미, 학교의 게스트 모드 변경·복구 시점, CEU 별도 해제 요청의 적용 범위는 확인 필요로 남긴다.
