# Phase 4 검토 및 반영 기록

Phase 4에서는 원본 자료를 기존 상세 페이지와 대조하고, 발견 사항을 페이지에 반영한 다음 결과를 재검토했습니다. 정책이 자료마다 다른 항목은 기존처럼 ‘확인 필요’로 남겼습니다.

## 1차 검토 — 원본과 Phase 1~3 비교

검토 자료는 `reference/`의 PDF 2개, PPTX 1개, DOCX 1개, TXT 1개, 이미지 4개입니다. PDF·PPTX·DOCX·TXT의 읽을 수 있는 텍스트와 라벨 이미지를 확인했습니다. 기존 출처표 `pages/sources.html`의 문서 범위·쪽수도 대조했습니다.

| 검토 항목 | 확인한 자료 근거 | 검토 피드백 |
|---|---|---|
| 사업 흐름·판정·일정·학교 준비·관리전환·문의 | 시행 가이드 PDF 3~67쪽, 실무가이드 PDF 3~15쪽, PPTX 해당 슬라이드, 상담스크립트 | 핵심 절차와 출처가 이미 페이지에 있습니다. 버전·운영기준 차이는 확인 필요로 유지합니다. |
| 품목·보급 단말 식별 | 시행 가이드 PDF 5~6·10쪽, TXT 1)~2), 라벨 이미지 1~3 | 기존 페이지는 2024년 상·하반기만 언급합니다. TXT의 2022·2023·2025·2026 연도 구분과 2024년 OS별 모델 표를 추가하면 A/S 문의 안내에 도움이 됩니다. |
| 수거·펜·수리·일정 충돌 | PDF 5·9·11·13·38~39·59쪽, PPTX 슬라이드 9·11·39·67 | 이미 구체적 확인 필요와 출처로 표시되어 있으므로 임의로 기준을 선택하지 않습니다. |
| 개인정보·이미지 사용 | 라벨 예시 4개와 명렬표·계정 설명이 포함된 PDF/PPTX | 실제 라벨 이미지를 새로 게시하지 않습니다. 화면에 보이는 학생 계정·비밀번호 예시도 옮기지 않습니다. |
| Phase 3 정적 검색 | `assets/js/common.js`의 `searchPages` | HTML 수정 시 색인 동기화가 필요합니다. |

### 1차 피드백에 따른 수정

- `pages/business/collection.html`: TXT의 2022~2026 관리 사업자 구분과 시행 가이드 PDF에 실린 2024 OS별 제품명·모델 표를 추가했습니다.
- `pages/sources.html`: 페이지 대응표의 근거·요약과 라벨 이미지 설명을 보완했습니다.
- 라벨에 보이는 개인·학교 식별정보는 추가하지 않았습니다. 2024 표를 현재 보유기기 목록으로 일반화하지 않도록 적용 범위도 덧붙였습니다.

## 2차 검토 — 수정본과 검색·출처·범위 대조

수정 뒤 다음 항목을 검토했습니다.

| 항목 | 결과 및 적용 가능한 피드백 |
|---|---|
| 사실·출처 대응 | 연도 구분은 TXT 2), 2024 모델은 시행 가이드 PDF 6쪽으로 각각 인용했습니다. 서로 다른 범위의 근거가 한 출처로 뭉치지 않도록 출처를 분리했습니다. |
| 검색 색인 | 수정된 수거 페이지·출처표를 포함해 전체 공개 HTML 14개의 본문 색인을 다시 생성했습니다. |
| 링크·정적 직접 접속 | 새 내용은 기존 상세 페이지 안의 표라 새 경로가 추가되지 않습니다. 기존 상대경로 출처 링크와 표의 모바일 가로 스크롤을 다시 점검합니다. |
| 충돌·정책 확정 | 콜센터 번호, 일정 주차, 미충전·수리·전용펜 처리 등 기존 확인 필요 사항을 변경할 근거가 없습니다. 모두 유지합니다. |
| 정보 보호 | 검색 색인에는 사람이 읽는 페이지 본문만 포함하고 라벨 원본 파일·학교/학생 실정보·로그인 비밀정보는 포함하지 않습니다. |

### 2차 피드백에 따른 수정

- `assets/js/common.js`의 정적 검색 색인을 현재 HTML 전체에서 다시 만들어 업데이트했습니다.
- 수정한 표를 포함해 내부 링크·앵커·출처 연결과 모바일 표 스크롤을 재검사했습니다.
- 수정 사항은 기존 구조의 HTML 표와 공통 검색 색인에 반영했습니다. 빌드 도구나 새로운 기능은 추가하지 않았습니다.

## 재검토 후 남은 확인 목록

아래는 원본만으로 확정할 수 없거나 Phase 4 범위를 넘어 실제 운영자 확인이 필요한 항목입니다.

- 양품화 콜센터 대표번호(PDF의 1566-6647과 PPTX의 1566-6747), 실제 운영시간과 문의 메뉴 명칭
- 수리동의서 제출·부착 방식과 수리 필요·미충전·케이스 파손 기기의 현장 처리
- 전용펜 수거확인서 수량 항목의 의미 및 학교별 지급 확정 수량
- 10월 공문 안내 주차 차이, 개통일과 요일 표기
- 2027년 학교별 배부 일정·구성품의 최종 확정 안내
- 이미지 형태로만 확인 가능한 서식·화면 문구의 별도 텍스트 원본

이 목록은 자료 간 확인 필요 항목을 대신하지 않습니다. 원본에서 차이가 남아 있으면 계속 출처와 함께 표시합니다.
