# Phase 4 재검토 기록

현재 사이트의 업무 페이지 12개와 홈·문의 페이지를 원본 자료와 다시 대조했습니다. 공개 페이지에는 출처를 길게 노출하지 않고, 확정할 수 없는 운영 기준만 간결하게 확인 필요로 표시합니다.

## 확인한 원본 범위

- reference/의 시행 가이드 PDF 2종, 연수 PPTX, 상담스크립트 DOCX, 기기 구분 TXT, 라벨 이미지 4개
- 이번 재검토에서는 PPTX 슬라이드 텍스트와 TXT를 직접 확인하고, PDF·DOCX의 기존 검토 기록 및 현재 페이지 반영 상태를 대조했습니다. 화면 이미지 안의 미추출 문구는 새로 추측하지 않았습니다.

## 2026-10-22 수거 희망 일정 변경 보완

- 기존 일정 페이지와 연수 PPTX 55~57번 슬라이드의 추출 텍스트에서 일반 변경 신청·매니저 확인·승인완료 흐름을 확인했습니다. 상담스크립트 DOCX 추출 텍스트에서는 관련 추가 안내를 찾지 못했습니다. 이번 확인에서 PDF와 화면 이미지 안의 문구는 재검증하지 않았습니다.
- 승인완료 후 시스템에서 변경 신청이 불가능할 수 있으며, 이 경우 담당 양품화 매니저에게 직접 연락해 조정한다는 예외는 사용자가 제공한 운영 기준(2026-10-22)을 근거로 추가했습니다.
- 일정 페이지의 메뉴 경로·학교 대응·주의 안내, 문의 페이지와 두 페이지의 검색 색인을 함께 갱신했습니다.

## 2026-10-22 파손·분실 본인부담 안내 추가

- 기존 페이지와 참고자료 PPTX·DOCX 추출 텍스트에서 본인부담률·상한액 안내를 찾지 못했습니다. PDF·이미지 문구는 이번에 재검증하지 않았습니다.
- 사용자가 제공한 기준을 근거로 학생 과실 파손은 20%·최대 4만 원, 기기 분실은 90%로 현장 점검·판정 페이지에 추가했습니다.
- 분실 부담률을 적용할 기준 금액은 제공되지 않아 확인 필요로 표시했으며, 파손의 4만 원 상한을 분실에 적용하지 않았습니다.
- 문의 페이지에서 본인부담 기준으로 연결하고 두 페이지의 검색 색인을 갱신했습니다.

## 2026-10-22 수거 전 사전 연락 안내 추가

- 사용자가 제공한 운영 안내를 근거로 일정 확인·변경 페이지에 ‘수거 예정일 3일 전까지 수거 담당 기사님이 학교로 연락드릴 예정’임을 추가했습니다.
- 영업일 기준 여부·연락이 오지 않았을 때의 별도 절차는 제공되지 않아 추가하지 않았습니다. 해당 페이지의 검색 색인도 갱신했습니다.

## 2026-10-22 펜슬 안내 PDF 직접 검토·반영

- reference/2027년 디벗 양품화 펜슬 안내.pdf 총 2쪽을 Windows PDF 렌더러로 이미지화해 두 페이지의 본문·표·예시를 모두 직접 확인했습니다.
- 1쪽: 실제 2027년 보급 대수 기준 윈도우·안드로이드·크롬·웨일 정품펜슬 15%, 애플 호환펜슬 20%. 회수 대수 기준이 아니며 배터리 불량 교환분은 미포함입니다.
- 2쪽: 서울시교육청 한시적 예산으로 2024년 보급 애플 1세대 정품펜슬 배터리 불량품 교환. 사전 보고·실물 반납 필요, 두 수량 중 적은 수량만 호환펜슬로 재보급하며 사업자 제공분과 합산합니다.
- 기존 연수자료 및 사이트 일괄 15%와 새 문서 애플 20%의 차이는 상세 페이지에 두 출처와 확인 필요 안내를 남겼습니다. 과거 검토 기록의 일괄 15% 서술은 당시 기록입니다.
- 배부·설치 상세와 사업 배부 요약, 수거 품목·당일 안내 및 해당 검색 색인을 수정했습니다. 사전 보고 제출 경로·기한과 비정수 수량의 반올림 기준은 문서에 없어 추가하지 않았습니다.

## 2026-10-22 디벗관리시스템 구분 안내

- 사용자가 전달한 2026-10-22 운영 대화의 답변을 근거로 문의 페이지에 시스템 비교표를 추가하고 일정 페이지 로그인 단계에서 연결했습니다. 외부 사이트의 현재 운영 상태를 별도로 조회한 결과가 아닙니다.
- dibeot.kr은 TGS·KT 측 2026년 6차 보급사업 운영 및 2023년·2024년 상반기(선도학교)·2026년 보급사업 관리용으로 전달되었습니다. 상세 사용 방법은 KT 측에서 공유받지 않았다는 안내를 반영했습니다.
- 양품화 업무용 시스템 주소는 기존 프로젝트의 dbs.edu-portal.ai를 유지하고, 학교 관리용·인터넷 검색 불가라는 전달 내용을 접속 안내에 반영했습니다.
- 대화에 포함된 학교명·성명·전화번호는 파일과 검색 색인에 옮기지 않았습니다.
- 함께 전달된 크롬북 바닥 고무발 탈락 문의는 답변이 없어 수거 가능 여부·A/S 선행 여부를 확정하지 않았습니다. 이후 사용자가 제공한 답변으로 아래 고무 루버 안내에 반영했습니다.

## 2026-10-22 고무 루버·키보드 부품 안내 보완

- 사용자가 제공한 운영 답변을 근거로 기존 미확인 크롬북 고무발 문의를 갱신했습니다. 루버 자체는 양품화 수거 대상이 아니지만 없어도 본체 수거가 가능하며, 양품화 시 신규 부착·새 부품 지급은 하지 않습니다.
- 필요한 경우 별도 서비스 신청, 행정실을 통한 20~30개 일괄 구매 사례를 안내했습니다. 구매 사례를 의무 수량으로 표현하지 않았습니다.
- 삼성 크롬북에 한정해 1개 1,000원·4개 4,000원·학생 직접 구매 동일 가격을 기록하고, 프론트/리어 부품이 달라 같은 종류 4개 구매 금지 안내를 추가했습니다. 위치별 수량·부품번호·부착 방법은 제공되지 않아 만들지 않았습니다.
- 키보드 고무 마킹 등 부품 수리·교체는 A/S 요청으로 안내합니다. 수거 품목 상세·현장 판정·문의 페이지와 검색 색인을 갱신했습니다.
