# Phase 4 재검토 기록

현재 사이트의 업무 페이지 12개와 홈·문의 페이지를 원본 자료와 다시 대조했습니다. 공개 페이지에는 출처를 길게 노출하지 않고, 확정할 수 없는 운영 기준만 간결하게 확인 필요로 표시합니다.

## 확인한 원본 범위

- reference/의 시행 가이드 PDF 2종, 연수 PPTX, 상담스크립트 DOCX, 기기 구분 TXT, 라벨 이미지 4개
- 이번 재검토에서는 PPTX 슬라이드 텍스트와 TXT를 직접 확인하고, PDF·DOCX의 기존 검토 기록 및 현재 페이지 반영 상태를 대조했습니다. 화면 이미지 안의 미추출 문구는 새로 추측하지 않았습니다.

## 전체 페이지 대조 피드백 및 반영

| 항목 | 대조 결과와 조치 |
|---|---|
| 사업 흐름·품목·학교 준비·OS별 준비·일정·수거확인서·명렬표·설치확인 | 기존 페이지에 주요 단계가 있습니다. 세부 화면의 현재 메뉴명·상태값은 실제 시스템에서 확인해야 합니다. |
| 일반 수리 필요 기기와 현장 예외 | 자료는 일반 불량 기기의 A/S 선행과 수거 당일 발견 기기의 동의서 확인 후 현장 처리 예외를 구분합니다. 현장 판정 페이지가 두 경우를 한 기준처럼 표현해 구분을 명확히 했습니다. |
| 수리동의서 | 자료에는 시스템 신청·취합과 종이 동의서 부착 절차가 모두 나옵니다. 둘의 대체 관계는 확정할 수 없어 확인 안내를 유지했습니다. |
| 콜센터 대표번호 | 연수자료 안에 1566-6647과 1566-6747 표기가 함께 있습니다. 문의 페이지에서 특정 번호를 확정값처럼 노출하지 않고 최신 안내 확인으로 변경했습니다. |
| 15% 지급 품목 | 연수자료의 관리전환·구성품 슬라이드 사이에 펜슬과 전용펜 표기가 다릅니다. 사용자가 확정한 펜슬 15% 기준을 사이트에 유지하고, 원자료 표기 차이는 이 내부 기록에 남겼습니다. |
| 모델·관리 사업자 구분 | 기존 수거 품목 페이지에 연도별 구분과 2024년 모델 표가 있습니다. 실제 학교 보유기기는 라벨과 목록으로 확인하도록 범위를 제한했습니다. |
| 개인정보·계정 | 학교·학생 식별정보, 실제 계정·비밀번호, 라벨 원본 이미지는 게시하지 않았습니다. |
| 검색 | 수정한 페이지를 포함해 전체 HTML 본문 정적 색인을 갱신했습니다. |

## 이번 변경

- pages/business/inspection.html: 일반 A/S 선행과 수거 당일 현장 발견 예외를 구분하고 학교 수리동의서 안내로 연결
- pages/contact.html: 충돌하는 대표번호를 확인 필요로 바꾸고, 안내 전 최신 공지 확인 문구 추가

## 남은 확인 사항

- 시스템 제출과 기기 부착용 종이 동의서의 실제 적용 관계
- 콜센터 대표번호·운영시간·내선, 온라인 문의 메뉴명
- 15% 구성품 기준의 공식 문서 정합성 및 학교별 최종 배부 수량
- 시스템 화면의 현재 메뉴명·상태와 학교별 일정·수량
- 이미지로만 확인 가능한 서식·화면 문구의 텍스트 원본
