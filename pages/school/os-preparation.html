학교가 할 일

?

이 단계에서 학교가 진행할 절차입니다.

모든 OS에서 개인데이터 삭제 여부를 확인합니다. 차단 정책 해제는 학교가 관리자 계정으로 직접 수행하며, 수거담당자는 완료 여부를 확인합니다.

관리자 작업 상세

OS별 관리 도구·계정·정책 상세 안내에서 학교 작업 순서를 확인하세요. 크롬북 Google Workspace·CEU, 아이패드 MDM·ASM, 웨일북 관리 기기 제외를 구분해 안내합니다.

2027 양품화 자료와 2025 기기 매뉴얼을 대조했습니다. 게스트 모드·AMA 정책의 양품화 중 임시 허용과 작업 후 복구도 함께 확인하세요.

확인 방법

  • 안드로이드: 적용된 AMA·Android 정책에서 양품화 작업 중 공장초기화·USB 전송을 한시 허용하고 저장합니다. 작업이 끝나면 평상시 차단 상태로 복구합니다.
  • 아이패드: 적용 정책 [상세] → 차단 영역 [수정]에서 계정 설정, 공장초기화, USB 관련 항목과 외부 PC 페어링을 확인합니다.
  • 윈도우: 적용 정책 [상세] → 차단 영역 [수정]에서 USB 제한 모드·USB 파일 연결을 허용하고 저장합니다.
  • 크롬북: Google 관리 콘솔에서 양품화 중 파워워시·게스트 모드를 한시 허용합니다. 작업 후 학교의 평상시 차단 설정으로 복구합니다.
  • 웨일북: 시간 영역 → 전원 → 로그아웃을 확인합니다. 어드민의 Whalespace 관리 기기 → 모든 기기 보기 → 대상 선택 → 관리 기기에서 제외 후 안내에 동의하고 확인합니다.

안드로이드는 개별 [저장] 후 하단 [변경 사항 저장] → [확인]까지 진행합니다. 아이패드·윈도우에는 이 하단 메뉴가 없을 수 있으므로 표시 여부를 확인하세요.

준비 시 필수 확인

초기화 차단 해제는 필수, 기기 초기화는 선택입니다. 계정 삭제·로그아웃·차단 해제와 초기화 실행을 같은 작업으로 안내하지 마세요. 웨일북은 별도 초기화 차단 기능과 관계없이 관리 기기에서 제외해야 합니다.

해당하는 경우 추가 확인

?

기본 절차와 별도로, 해당 상황에 맞는 항목만 펼쳐 확인하세요.

안드로이드 AMA 정책을 양품화 중 임시 허용하는 경우

학교 관리자 계정으로 AMA 통합설정에서 양품화 대상 학년에 적용된 정책을 확인합니다. 소프트웨어 업데이트와 포맷을 위해 양품화 작업 중 관련 차단을 한시 해제하고, 작업을 마치면 평상시 차단 상태로 복구합니다.

  1. 좌측 메뉴에서 통합설정을 엽니다.
  2. 양품화 대상 학년에 적용할 정책을 찾습니다. 정책 이름의 예시는 ‘학교명_AMA 정책 3학년’ 형식입니다.
  3. 해당 정책의 옵션 열에서 [상세]를 클릭합니다.
  4. 모달 창에서 양품화 작업 중 공장초기화·USB 전송이 허용되는 상태로 변경합니다. 화면에서 ‘차단 해제’를 켜거나 ‘차단’을 끄는 방식으로 보일 수 있으므로 항목의 실제 기능을 확인합니다. 양품화 작업이 끝나면 같은 정책에서 평상시 차단 상태로 되돌립니다. 작업 중 임시 허용·복구 안내
  5. 모달 창 하단의 [저장]을 클릭합니다.
  6. 창이 닫히면 통합설정 페이지 하단의 [변경사항 저장]을 클릭합니다.
  7. 양품화 작업을 마친 뒤에는 같은 AMA·Android 정책에서 공장초기화·USB 전송을 다시 차단하고 변경사항을 저장합니다.

적용 정책을 모를 때

  1. 좌측 메뉴의 두 번째 항목인 단말현황을 엽니다.
  2. 화면 오른쪽 위의 CSV 다운로드 아이콘을 선택해 [단말 정보 다운로드]를 실행합니다. 학교에 소속된 단말 정보가 CSV 파일로 내려받아집니다.
  3. 내려받은 CSV 파일을 엑셀에서 엽니다. 학교 소속 단말의 기기 정보가 표로 표시됩니다.
  4. 양품화 대상 학년 기기 뒷면 라벨에서 시리얼넘버를 확인합니다.
  5. 실제 기기 라벨의 시리얼넘버 앞 4자리와 엑셀의 기기 정보에서 시리얼넘버 앞 4자리가 같은 행을 찾습니다.
  6. 찾은 행의 [적용정책] 열을 확인합니다. 해당 열의 값이 통합설정에서 찾아야 할 정책 설정 이름입니다.
  7. 통합설정으로 돌아가 해당 정책 설정을 찾아 양품화 대상에 필요한 차단 해제를 진행합니다.

단말 정보 다운로드 기능은 참고 문서에 명시되어 있습니다. 시리얼넘버 앞 4자리 대조 절차는 사용자 별도 제공 정보입니다. 시리얼넘버와 적용 정책을 직접 대조해 대상 기기의 정책을 확인합니다. 학교명·기기 식별정보가 포함된 내려받은 자료는 외부에 공개하지 마세요.

계정·잠금 해제를 완료하지 못한 경우

학교 준비를 완료하고 미해제 항목은 담당자에게 확인하세요. OS별 처리 가능 여부가 다릅니다.
