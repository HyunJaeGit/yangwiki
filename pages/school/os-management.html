OS별 관리자 작업 상세

양품화 수거 전에 학교가 확인할 관리 도구와 설정입니다. OS별 준비 요약표와 함께 확인하세요.

작업 범위부터 확인

2027학년도 양품화 자료에 명시된 준비 절차에 2025년 기기 매뉴얼의 관리 도구 설명을 보충했습니다. 작업을 위해 평소 차단하는 일부 정책은 양품화 중 한시적으로 허용하고, 작업 완료 후 평상시 차단 상태로 되돌립니다. 실제 기기 초기화 실행 여부는 별도 작업 선택입니다. 필요한 개인 자료는 삭제 전에 백업하도록 안내합니다.

관리 화면에서 공통으로 확인할 순서

  1. 대상과 수량을 확정합니다. 학교가 안내받은 OS·모델별 양품화 수량과 실물 기기를 비교하고, 기기 라벨의 시리얼번호를 이용합니다. 사용자가 관리하는 화면의 계정 목록과 기기 목록은 서로 다를 수 있습니다.
  2. 기기가 관리 시스템에 등록되어 있는지 찾습니다. 등록된 기기라면 현재 조직·그룹·적용 정책을 확인합니다. 조직 단위는 설정을 묶어 적용하는 분류입니다.
  3. 실물 시리얼번호와 화면의 기기 정보를 대조합니다. 이름이나 화면에 보이는 수량만으로 대상 기기라고 판단하지 않습니다.
  4. 확인된 기기에만 필요한 변경을 합니다. 조직 이동, 정책 수정, 초기화는 서로 다른 작업입니다. 수거 안내에서 요구한 것만 수행합니다.
  5. 변경 뒤 대상 수량·정책 상태를 다시 확인합니다. 기기를 옮기면 새 조직의 정책이 적용될 수 있으므로 파워워시·게스트 모드 등 양품화 설정을 재확인합니다.

관리 화면·조직 단위의 이름과 기능은 OS마다 다릅니다. 아래 순서는 ‘대상 확인 → 해당 관리 화면에서 조회 → 시리얼 대조 → 해당 기기의 설정을 점검’하는 공통 확인 흐름이며, 한 시스템의 메뉴 경로를 다른 OS에 그대로 적용하지 않습니다. 계정·비밀번호나 시리얼 목록을 공개 채널에 공유하지 마세요.

과거 매뉴얼의 화면과 현재 학교 화면이 다르면 메뉴 이름·대상 기기·최종 허용 상태를 확인하세요.

크롬북 · Google Workspace와 CEU

Google Workspace 관리 콘솔은 학교 계정·조직과 기기 설정을 관리하는 화면입니다. 사용자 계정은 사용자 관리 메뉴에서, 크롬북 실물은 기기 → Chrome → 기기에서 조회합니다. 사용자 계정 수와 관리되는 기기 수는 서로 다른 수량입니다. CEU(Chrome Education Upgrade)는 크롬OS 기기 관리에 사용하는 업그레이드이며, 관리 콘솔의 기기 정책과 연결됩니다.

양품화 작업 중 임시 설정

  1. 학생이 필요한 자료를 백업하고 개인데이터를 삭제했는지 확인합니다.
  2. 학교 관리자 계정으로 Google 관리 콘솔(admin.google.com)에 접속합니다.
  3. 기기 → Chrome → 설정 → 기기 설정에서 양품화 대상 기기의 조직 단위를 확인합니다. 연수자료에서는 이 경로를 ‘기기 → 설정 → 조직 단위’로 표기합니다.
  4. 양품화 중 소프트웨어 업데이트와 포맷에 필요하므로 파워워시를 ‘파워워시가 트리거되도록 허용’으로 설정하고 저장합니다.
  5. 양품화 작업 중 사용할 수 있도록 게스트 모드를 ‘게스트 모드 허용’으로 임시 설정합니다.
  6. 양품화 작업이 끝나면 파워워시와 게스트 모드를 평상시 학교 정책에 따라 다시 차단하고, 적용된 조직 단위의 설정을 확인합니다.

기기별 CEU 등록 여부와 현재 설정 상태는 학교 관리자 화면에서 확인하세요.

대상 수량이 관리 콘솔보다 적게 보이는 경우

양품화 대상 수량보다 조직 단위에서 보이는 수량이 적더라도, 그 차이만으로 미등록·CEU 누락이라고 단정하지 않습니다. 우선 관리 콘솔의 기기 목록 전체에서 대상 기기의 위치를 확인합니다.

  1. 학교 관리자 계정으로 admin.google.com → 기기 → Chrome → 기기를 엽니다. 2025 매뉴얼에도 이 화면에서 크롬북 기기 현황을 확인하도록 나옵니다.
  2. 양품화 대상 실물 기기의 라벨 시리얼번호를 확인하고, 기기 목록에서 같은 번호를 검색합니다. 한 기기씩 실물과 화면을 대조해 학교의 양품화 대상 목록에 있는 기기인지 확인합니다.
  3. 기기가 검색되면 상세 정보에서 현재 조직 단위를 확인합니다. 이 기기가 다른 조직에 있는 경우에만 다음 단계로 갑니다.
  4. 실물과 대상 목록이 일치하는 기기만 선택해 세부 메뉴의 기기 이동·조직 단위 변경 기능으로 양품화 대상 조직 단위에 옮깁니다. 화면에서 완료를 확인합니다. 다른 학교·다른 용도의 기기는 옮기지 않습니다.
  5. 양품화 대상 조직 단위의 기기 수량을 새로고침해 다시 확인하고, 해당 조직에 적용된 파워워시·게스트 모드 설정도 확인합니다. 조직 단위별로 설정을 달리할 수 있고 상위 조직 설정이 하위 조직에 적용되는 경우가 있으므로, 이동 뒤 정책 상태를 재확인합니다.

여러 기기 선택 기능은 안내되어 있지만, 조직 이동을 한꺼번에 처리할 수 있는지는 제공 자료에서 확인되지 않습니다. 각 기기의 시리얼을 확인한 뒤 화면에서 지원하는 이동 방법을 따르세요.

검색해도 기기가 없거나 이동할 수 없는 경우

먼저 시리얼번호를 다시 확인하고 목록 검색 조건·새로고침·로그인 계정의 조회 범위를 확인합니다. 학교 관리 권한은 담당 조직 단위로 제한될 수 있으므로 조회 범위를 관리자에게 확인합니다.

다른 조직과 계정에서도 찾을 수 없거나 이동 권한이 없다면, 학교 Google Workspace 최고 관리자 또는 Chrome 기기 관리 권한이 있는 관리자에게 확인을 요청합니다. 참고 문서에는 CEU 누락 기기의 개별 등록 제목만 있고, 실제 등록 작업 순서는 제시되어 있지 않습니다. 따라서 미등록 기기의 신규 등록 방법이나 요청처를 이 자료만으로 안내할 수 없습니다. 기기 등록·라이선스 상태를 담당 관리자에게 확인하고, 임의로 프로비저닝 해제를 진행하지 않습니다.

CEU 확인과 관리전환 구분

  • 2025 매뉴얼은 기기 → Chrome → 기기에서 CEU 현황을 확인하도록 설명합니다. 기기 초기화 후에도 정책·등록을 유지하거나 강제 재등록하는 설정이 있으므로, 파워워시 허용·실행과 CEU 해제는 서로 다른 작업입니다.
  • 2027 실무가이드에서 크롬북 관리전환은 양품화 사업자 작업입니다. 학교의 수거 전 필수 작업 목록에 CEU 프로비저닝 해제를 추가하지 않습니다.
  • 관리전환에 필요한 최고관리자 접속 정보와 2단계 인증을 위한 학교 담당자 연락처는 명렬표 제출 시 디벗관리시스템으로 제출하도록 안내되어 있습니다. 명렬표·관리전환 안내에서 시기를 구분해 확인하세요.

CEU 해제와 라이선스 회수는 양품화 사전 작업으로 안내된 내용이 아닙니다. 별도 요청을 받으면 대상·사유·사업자 작업 범위를 확인하세요.

안드로이드 · 계정과 적용 정책 확인

정책 메뉴 경로: 학교 스마트 단말 관리시스템(Argos MDM) → 단말현황에서 대상 단말과 적용 정책을 확인합니다. 메뉴의 통합설정에서 정책 목록·상세를 열어 차단 항목을 수정합니다. AMA 매뉴얼에서는 단말현황의 조직·검색·필터·엑셀 다운로드와 통합설정 메뉴를 각각 설명합니다.

  1. FamilyLink, 구글·삼성 계정 로그아웃과 화면 잠금 해제를 확인합니다. 2025 매뉴얼의 Google 계정 초기화는 삼성 계정을 로그아웃하지 않습니다. 삼성 계정은 별도로 확인합니다.
  2. 단말현황 → 검색/필터 또는 단말 정보 다운로드로 기기를 찾습니다. 실물 시리얼과 단말 목록을 대조한 후, 해당 행의 적용 정책을 확인합니다. 사용자가 안내한 시리얼 앞 4자리 대조 방법은 AMA 적용 정책 찾기를 참고합니다.
  3. 통합설정 → 대상 정책 → 상세에서 차단 영역을 확인합니다. 양품화 작업 중 소프트웨어 업데이트·포맷에 필요한 공장초기화·USB 전송을 한시 허용하고 저장합니다. AMA·Android 두 정책이 모두 적용되어 있으면 각각 확인합니다.
  4. 통합설정 화면에 하단 [변경사항 저장]이 표시되면 눌러 반영합니다. 다시 대상 기기와 적용 정책을 확인합니다.

양품화 작업을 완료한 뒤에는 해당 정책을 학교의 평상시 차단 상태로 복구하고, 대상 기기에 적용된 정책을 확인합니다.

기존 AMA 상세 절차·적용 정책 찾기

단말 정보 다운로드 기능과 시리얼 앞 4자리로 CSV 행을 찾는 안내는 출처가 다릅니다. 시리얼 앞 4자리 대조는 별도 사용자 제공 정보입니다.

아이패드 · MDM과 ASM 구분

MDM 경로: 서울시교육청 Argos MDM → 단말현황에서 기기를 확인하고, 통합설정에서 정책을 확인·수정합니다. ASM은 관리형 Apple 계정과 사용자를 관리하고, 기기 정책 수정은 MDM에서 합니다. MDM과 ASM은 연동될 수 있지만 같은 화면이나 같은 관리자 작업은 아닙니다.

  1. 수합 전에 MDM → 통합설정 → 대상 정책 [상세] → 차단 → 사용자 설정/계정 설정에서 계정 설정 차단을 허용하고 저장합니다. 학생이 계정을 로그아웃할 수 있도록 학교가 먼저 처리하는 단계입니다.
  2. 개인데이터 삭제, 화면 잠금 해제, 기기의 ASM 사용자 계정 로그아웃을 확인합니다.
  3. 수합 후 같은 MDM 통합설정 상세에서 공장초기화, USB 제한 모드·USB 파일 연결, 외부 PC 페어링 차단을 허용으로 바꾸고 저장합니다. MDM의 단말현황에서 대상 단말의 상태를 확인합니다.

MDM의 기기 비밀번호 초기화와 ASM의 Apple 계정 관리는 별개입니다. 졸업생 계정 삭제·SFTP 학적 정리는 별도 계정 관리 업무이며, 기기에서 로그아웃하는 수거 준비와 동일한 작업으로 안내하지 않습니다.

윈도우 · USB 차단 해제와 초기화 구분

관리 경로: 2025 윈도우 매뉴얼은 Argos for Windows의 학교 관리 시스템에 단말현황·통합설정 메뉴가 있음을 안내합니다. 크롬북용 Google Workspace나 CEU 메뉴가 아니라 학교 스마트 단말 관리시스템에서 확인합니다.

  1. 필요한 자료 백업과 개인데이터 삭제 여부를 확인합니다.
  2. 단말현황에서 대상 윈도우 기기와 적용 정책을 확인합니다.
  3. 통합설정의 대상 정책 상세 → 차단 영역 수정에서 USB 제한 모드·USB 파일 연결을 허용하고 저장합니다.
  4. 단말현황에서 대상 기기·정책을 다시 확인합니다.

2025 매뉴얼은 졸업생 기기의 공장초기화를 관리 업체에 맡기도록 설명합니다. 2027 실무가이드도 초기화를 선택 작업으로 구분하고 유지보수 업체를 통한 복원 이미지 USB 초기화를 안내합니다. 학교의 필수 작업에 직접 OS 재설치를 추가하지 않습니다.

졸업생 계정 삭제 절차는 양품화 수거 절차와 구분합니다.

웨일북 · 로그아웃 후 관리 기기에서 제외

관리 경로: Whalespace Admin → 기기 → 관리 기기에서 학교 조직에 등록된 기기, 시리얼번호와 등록 사용자를 확인합니다. 구성원 메뉴는 사람 계정 관리이므로 기기 확인 메뉴와 구분합니다.

  1. 필요한 자료 백업·개인데이터 삭제 후 시간 영역 → 전원 → 로그아웃으로 웨일스페이스 계정을 로그아웃합니다.
  2. 관리 기기 목록에서 실물 시리얼과 등록 사용자 등으로 대상 단말을 확인합니다.
  3. 양품화 학교연수자료에 따른 관리 기기 제외가 필요한 수거 후 단계라면, 대상 단말을 선택해 관리 기기에서 제외를 진행합니다. 화면 안내를 확인하고 완료 상태를 확인합니다.

기기 초기화, 관리 기기에서 제외, 구성원 계정 삭제는 각각 다른 작업입니다. 졸업생 구성원 일괄 삭제를 양품화 수거 전 필수 절차로 보지 않습니다. 관리전환은 양품화 사업자 작업으로 구분합니다.

정책 적용 시점

크롬북 게스트 모드 · 평상시 차단, 양품화 중 한시 허용

두 자료는 서로 다른 사용 상황을 설명합니다. 평상시 수업에서는 게스트 모드를 차단하고, 양품화 중 소프트웨어 업데이트·포맷을 진행할 때만 임시로 허용합니다. 양품화 작업이 끝나면 학교의 평상시 정책대로 다시 차단합니다.

AMA 공장초기화·USB 전송 · 양품화 중 한시 허용

양품화 작업 중 소프트웨어 업데이트와 포맷을 진행할 수 있도록 공장초기화·USB 전송 차단을 한시 해제합니다. 작업 완료 후에는 평상시 학교 정책에 따라 다시 차단합니다.

관리 화면은 ‘차단 해제’ 항목의 활성화나 ‘차단’ 항목의 비활성화로 표시될 수 있습니다. 색상보다 실제 기능이 작업 중 허용되고 작업 후 차단되는 상태인지 확인하세요.
